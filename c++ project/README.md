# My C++ for Studies

Учебный лёгкий код на C++ — простая программа, которая выводит приветствие

##  Описание

Программа выводит в консоль строку `Привет, мир!`.

## Как запустить

### Linux / macOS
```bash
g++ main.cpp -o hello
./hello
```

### Windows (MinGW)
```powershell
g++ main.cpp -o hello.exe
.\hello.exe
```

### Visual Studio
Создай Console App (C++), замени содержимое `main.cpp` и нажми F5.

##  Пример работы

```
Привет, мир!
```

## Чему учит

- Базовая структура программы на C++
- Подключение библиотеки `<iostream>`
- Вывод текста через `std::cout`
